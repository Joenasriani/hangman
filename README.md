# Hangman

This repository contains Joe Nasr's browser Hangman game work in two presentation variants:

- 2D build: `hangman-2d-index.html`
- 3D build: the GitHub Pages version from this repository

The 2D and 3D implementations are variants of the same **Hangman** game lineage, not separate games.

Existing branches and historical files are retained as development history.
